# Insurance-Quoter-Front

Frontend SPA del cotizador de seguros de daños. Implementado en Angular (última versión).

## Características
- Captura y visualización de cotizaciones, folios, ubicaciones y coberturas.
- Visualización de resultados y alertas.
- Experiencia de usuario intuitiva y moderna.

## Requisitos
- Node.js (versión recomendada en docs)
- Angular CLI

## Ejecución
```bash
npm install
ng serve
```

## Documentación
Consulta la carpeta `docs/` para guías de uso y especificaciones funcionales.
