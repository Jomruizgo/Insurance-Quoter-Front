1 · Átomos

Componentes indivisibles

Bloques mínimos de UI. En Angular serían componentes sin lógica de negocio, standalone, altamente reusables. Prefijo sugerido: sf- (Sofka).

2 · Moléculas

Combinaciones funcionales de átomos

Pequeños grupos con responsabilidad única. Reutilizables entre múltiples organismos.

3 · Organismos

Secciones funcionales autónomas

Piezas grandes con lógica de negocio o estado propio. Consumen servicios Angular (HttpClient, stores).

4 · Templates

Layouts sin contenido

Contenedores estructurales. En Angular: componentes de layout con slots (<ng-content>).

Sugerencias de implementación Angular

Mapeo a arquitectura

tokens
SCSS con variables CSS globales (misma estrategia que este prototipo). Cargar antes que Material/PrimeNG si se usan.
components/atoms
Standalone components puros, sin HttpClient ni Store. Cubrir con spec.ts unitarios (isolated).
components/molecules
Standalone, input/output. Pueden inyectar FormControl vía @Input.
components/organisms
Inyectan servicios (QuoteService, FolioService). Controlan estado local; para estado compartido usar signal store o NgRx Component Store.
features/folio
FeatureModule con rutas hijas — lazy-loaded. Resolver sobre GET /v1/quotes/:folio para hidratar el stepper de entrada.
state
Signals + computed para stepStatus derivado. Optimistic update: guardar versión previa antes del PUT/PATCH; rollback en 409 VERSION_CONFLICT.
a11y
FocusTrap en drawer/modal. Atajos: Esc cierra, ⌘K busca. Todos los switches/steps ya navegables por teclado en este prototipo.
i18n
@angular/localize · todas las cadenas en es-MX. Money / date con Intl API del runtime.
testing
Átomos y moléculas → Jasmine/Jest isolated. Organismos → TestBed con HttpClientTestingModule. Flujos → Cypress/Playwright: crear folio → capturar ubicación → calcular.
